⚙️ Admin Panel – Room Wise Control

Room select karein, phir uske liye Video Set, Chat Clear ya Stream Stop karein.

Yeh room ki abhi ki live video hai.
📡 Set New Video
Video set hote hi student ke player mein live aa jayegi.
🗑️ Clear Chat
Is room ki poorani saari chat delete ho jayegi.
⏹️ Stop Stream
Video ID delete ho jayegi, student ko "waiting" dikhega.
